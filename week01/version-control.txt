Version control means tracking the changes people make in a collaborative project. This happens through adding changes to a file, commiting those changes which acts like saving them, and push those changes to the server while also syncing to the server to recieve any changes that other people have made. The benefit to using version control is that when something goes wrong with the code or when you don't understand why something was added. You can look back to see when the change was made and what message the user that made the change attached. This better allows for understanding of someone else's code. One of the commands used in version control is git status. This is where you would want to start to see what action needs to take place.
